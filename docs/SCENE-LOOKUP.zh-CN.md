# 0.0.7 场景辅助补全

在 Builder 点击「查找 Danbooru Tag」。打开时会读取当前 Builder 的 tags；也可以在弹窗内手动粘贴或点击「读取当前 Builder」。原有 prompt 不会自动改写，只有点击插入才追加结果。

1. 「这次想补充什么」填写目标，例如：只补充蹲在墙角的姿势和位置，不要增加服装。
2. 展开「补充场景 / 已有 tags / 参考图」，可填写背景：雨夜小巷，人物躲避来人，环境已经写好。
3. 已有 tags 保留作上下文，后端按逗号或换行拆分，识别普通标签、别名和常见括号权重，排除重复建议。复杂提示词语法不做完整解析。
4. 可选一张参考图或 ControlNet 原图。也可完全不提供图片。文字要求优先，模型被要求只关注目标相关细节。
5. 查询后逐条复制或插入；组合可整体操作。已有标签与场景会帮助消歧，但不能保证模型语义理解正确。

参考图支持 PNG / JPEG / WebP，原文件最多 10 MB。应用在内存中缩到最长边 1280 像素，以 JPEG 发送到你配置的 LM Studio；不会修改原图或持久保存图片。场景与已有 tags 也只在当前弹窗组件内保留。API Token 继续保存在本机设置。

有图时，在 Mac 的 LM Studio 加载支持视觉输入的模型并选择对应模型 ID；纯文本模型不具备看图能力。若接口拒绝图片，移除参考图仍可使用文本查询。此功能是参考图辅助选标签，不执行 ControlNet、不生成图片。

「查看系统提示词」展示两阶段实际指令。源码位于 electron/tag-prompts.js，公共 JSON/不输出思考约束位于 electron/tag-lm.js。界面目前只读。

所有可插入标签必须来自本地候选并通过 SQLite 校验。结果说明由模型生成，未做语义验证；未找到不等于 Danbooru 没有。数据库没有在这次升级中更新，也无需重新导入。

验证：12 项相关自动测试通过，2 项 Mac 专用测试跳过。新增测试覆盖场景和参考图传输、无图查询、已有加权标签/别名排除、错误图片与超长输入拒绝、上下文查询幻觉拦截。Windows 安装包完成构建及 CRC 校验；尚未验证你的真实视觉模型或 Mac 打包。
