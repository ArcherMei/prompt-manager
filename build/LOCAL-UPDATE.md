# 本地安装包更新（0.0.3 起）

0.0.2 没有更新入口，首次升级需要手动安装 0.0.3。之后在「软件更新」选择新版
Windows EXE 或 Mac DMG，检查版本后确认「更新并退出」。不需要联网或更新服务器。

Windows：检查 EXE 头、产品名称与版本，复制到临时目录后启动原有 NSIS 安装向导。
沿用原安装目录完成安装；程序先退出避免占用，NSIS 管理安装权限与重启。
Mac：验证 DMG、bundle ID、版本、CPU 架构和应用签名完整性；先在目标同一文件系统
暂存应用，再由独立助手等待程序退出、替换应用并重新打开。替换失败尝试恢复旧应用。
原应用保留为同级隐藏的 `.Prompt-Manager-backup-时间戳.app`，更新页显示备份地址。
更新结果保存在 userData/local-update-result.json。暂存目录也保留供故障排查。

只接受较新的正式版本（数字版本号），阻止同版本重装与降级。产品信息和临时签名
不等于发行者身份验证，请仅选择自己构建或可信来源的安装包。没有修改 Gatekeeper、
隔离属性或系统签名策略。受保护/不可写目录、App Translocation、直接从 DMG 启动的
应用需要先手动安装到可写目录；不会自动提升权限。

更新只替换软件，不修改 userData 或模型/HTML 目录；更新前仍可使用 Backup 备份 tag，
仓库关联另在 userData/repository/library.json。Windows 实际安装需在 Windows 上验证。

验证记录：13 项自动测试通过；macOS 使用含更新入口的临时 0.0.2 测试构建，
选择正式 0.0.3 DMG 后完成版本检查、替换、重启，界面确认版本 0.0.3、旧应用备份，
并确认测试 tag、目录和手动匹配保留。此测试构建不等同于已发布的原始 0.0.2。
