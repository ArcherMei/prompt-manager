# LoRA 两个文件夹管理（0.0.4）

打开左侧「LoRA 文件管理」，展开「文件夹设置」。

- **LoRA 仓库文件夹**：存放全部模型和 HTML 使用说明。选择你已经整理好的文件夹，软件递归读取原文件，不自动搬移。不再创建模型编号文件夹或 `html-编号` 文件夹。从外部添加模型会复制到仓库根目录，HTML 放在所关联模型旁边；HTML 原有 `_files` / `.files` 资源文件夹保留。同名文件或资源不会覆盖。
- **ComfyUI 的 LoRA 模型文件夹**：ComfyUI 实际使用模型的位置，通常为 `ComfyUI/models/loras`。可选择自定义位置，包含全部子文件夹。只向这里复制模型，不复制 HTML。

这两个位置不能相同或互相包含。选择新的仓库文件夹只切换读取位置，不迁移旧仓库文件。旧位置的数据仍保留，重新选择旧位置即可查看。0.0.3 的单独扫描目录不再作为第三个入口；若原先没有 ComfyUI 目录，则沿用原扫描目录作为初始 ComfyUI 位置，请在设置中核对。

## 两个文件夹核对 / 复制

点击「核对两个文件夹」。程序递归扫描模型，用文件大小和 SHA-256 内容摘要判断另一边是否已经存在相同内容，即使文件名不同也能识别。

- ✅ 两边都有相同内容：显示另一边的相对路径。
- 缺少：可勾选复制；支持仓库 → ComfyUI 和 ComfyUI → 仓库。
- ⚠️ 同名不同内容：标记冲突，不自动覆盖。请在文件管理器中核实版本、改名或移到合适位置后重新核对。

点击复制后，选择目标根目录内的文件夹或子文件夹。勾选的模型直接放进所选位置，不自动复制来源的父目录结构，不携带 HTML。若目标出现同名文件，会跳过并报告。复制结果列出每个来源和目标完整路径。大模型第一次核对需要读取文件内容，请保持软件开启。

## 模型关联 Prompt

先选择查看 LoRA 仓库还是 ComfyUI 文件夹。这里的 ✅ / ✖️ 只表示模型是否关联了软件中的 Prompt 记录，不表示两边已同步，也不表示 HTML 齐全。

Main Note、Complex LoRA Tag、Prompt 正文、Sub-Note 都参与精确匹配。支持 `<lora:name:weight>`、`<lyco:name:weight>`、以逗号/分号/换行分隔的准确文件名；忽略大小写和模型扩展名。显示匹配依据，例如「Main Note → portrait_v2.safetensors」。不同子文件夹的同名模型需要带相对路径的名称或手动关联。

右侧显示记录的完整字段和分类路径。先点击左侧模型，再点记录的「关联到所选模型」，也可以拖动记录到模型名称上。包含模型名的长句只作为候选，不自动关联。支持多对多；取消后不会在下次扫描自动恢复，可点「恢复自动关联」。关联按文件完整路径保存，外部移动或重命名后需重新关联。

仓库同一层的同名 HTML 会自动关联；名称不同的 HTML 可以在「HTML 网页存档」中选择对应模型。显示名称修改不重命名磁盘文件。

## 导出仓库全部文件 ZIP

打包所选 **LoRA 仓库文件夹** 下的所有普通文件，包括模型、HTML、网页图片/样式等资源和全部子文件夹。不要求先关联 Prompt 或 HTML；没有 HTML 的模型也会导出。不跟随符号链接，完成后报告跳过的链接。

选择仓库以外的 ZIP 保存位置并使用新文件名，已有 ZIP 不覆盖。压缩包中的 `LoRA仓库/` 保留原始相对结构，`软件关联记录.json` 保存关联元数据和 Prompt 记录供备份核对；当前未新增一键恢复 ZIP 功能。使用 ZIP64 支持大文件，模型按原数据存储以避免无效压缩，大仓库需要足够磁盘空间。

原来的 JSON Backup / Restore 仍仅针对 Prompt，不包含模型或 HTML。

## 旧版编号文件夹整理

此操作只处理当前 LoRA 仓库文件夹中、软件索引已登记的旧版模型编号目录和 HTML 编号目录。先点「预览整理结果」，核对每个原文件和整理后路径，再点确认。

模型回到仓库根目录；HTML 及其资源放到对应模型旁边。存在同名冲突时整批阻止。先复制并更新关联，再移除原文件；无法清理的路径会报告。不会自动整理用户自己的普通子文件夹。

## 验证

自动测试涵盖递归扫描、Main Note/Complex LoRA Tag、持久手动关联、双向复制、内容核对、同名冲突、HTML 资源保存、ZIP 内容和旧目录整理。macOS 独立测试数据已验证按钮关联、实际复制及 ZIP 导出。Windows 安装包及内嵌卸载程序通过 NSIS CRC 校验；Windows 原生运行仍需在 Windows 上验证。
