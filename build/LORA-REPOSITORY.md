# LoRA 仓库（0.0.2）

左侧新增「LoRA 仓库」「HTML 网页存档」入口。

1. 选择「仓库目录」：导入的模型会复制到此处，每个 LoRA 一个独立子目录。
2. 添加模型文件，或递归导入文件夹。重复的来源路径会跳过。
3. 选中 LoRA，点击「保存 HTML」选择使用方法网页。HTML 和完整网页的
   `_files` / `.files` 资源会保存在该 LoRA 子目录内。单文件 HTML 直接保存。
4. 选择「本地 AI LoRA 目录」，指向本机 AI 软件使用的 LoRA 文件夹。
5. 点击「复制模型到 AI 目录」：仅复制模型文件，HTML 不会进入 AI 目录。
   已有同名同内容文件会跳过，同名不同内容文件会报错，绝不覆盖。

仓库显示与现有 prompt、extraTag、subNote 的精确名称匹配，支持
`<lora:name:weight>` / `<lyco:name:weight>`，忽略大小写与模型扩展名。
显示名称修改后，原名仍用于匹配。当前修改的是显示名称，不修改模型
实际文件名、AI 目录中的文件名或 prompt 文本。

HTML 网页可独立导入，再选择关联的模型；关联后会复制到该模型子目录。
预览支持离线 HTML、图片和样式，不执行脚本或请求远程资源。

改变仓库地址时会先复制已有模型和 HTML，成功后更新索引；原地址副本
保留。模型原始来源文件也保留。仓库文件失联会在界面标记。
目录通过系统文件选择器配置，Windows 和 macOS 各自保存本机路径。

仓库索引：软件 userData/repository/library.json。
原来的 JSON Backup / Restore 仍仅针对 prompt，不包含模型、HTML 或仓库索引；
备份仓库时请同时保存仓库目录和上述索引文件。

验证：`npm test`（递归导入/去重/失联、精确匹配、显示改名、HTML 资源副本、
自定义目录迁移、仅模型复制及冲突保护）。macOS 桌面实际验证了名称编辑、
tag 匹配、模型复制和 HTML/CSS 离线预览；Windows 运行需在 Windows 上验证。
